# Bacco Adega CRM — Identidade visual

Baseada na opção 3 aprovada.

## Paleta
- Bordô principal: `#4A0E1F`
- Dourado: `#C49A4A`
- Creme: `#F5F0E6`
- Grafite: `#2E2E2E`

## Tipografia
- Marca/títulos: Playfair Display (fallback: Cormorant Garamond / Georgia)
- Interface/textos: Inter

## Conceito
O símbolo combina a inicial **B** com um pequeno cacho de uvas, mantendo leitura premium e vínculo imediato com o universo do vinho. O dourado funciona como destaque e o bordô como cor institucional.
