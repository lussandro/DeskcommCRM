# Bacco Adega CRM — Brand & UI Kit

Pacote consolidado com identidade visual, logos vetoriais, telas de referência, temas light/dark, tokens para desenvolvimento e prompt mestre para novas telas.

## Estrutura
- `brand/svg/` — logos vetoriais.
- `brand/docs/` — identidade original.
- `brand/*.png` — brand boards e preview.
- `ui/screens/` — telas geradas.
- `ui/references/` — screenshots originais usados como referência.
- `ui/tokens/` — JSON e CSS com cores e tokens.
- `ui/prompts/` — prompt mestre de UI.
- `UI-GUIDE.md` — guia de design e implementação.

## Paleta
Borgonha `#4A0E1F` · Dourado `#C49A4A` · Creme `#F5F0E6` · Grafite `#2E2E2E`

## Tipografia
Playfair Display para títulos/editorial e Inter para UI.
